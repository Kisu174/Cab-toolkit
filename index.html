🧠 Catch a Brainrot Toolkit

Live data from the Indieun API · unofficial fan tool

⚠️ The Catch a Brainrot API does not publish an official damage formula, per-move damage values, energy costs, or healing amounts. This calculator combines the real numeric fields the API does expose (Attack stat, and Level / IV which you enter yourself, matching what appears in real inventory data) into a simple, transparent estimate. Anything not backed by real API data is clearly marked "not available" or left as an editable custom input, never invented.
